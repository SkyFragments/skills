## Slash Commands（快捷指令）

### 使用方式

```
/<指令名称>                 # 基本使用
/<指令名称> <参数>          # 带参数
/<指令名称> --<标志>        # 带标志位
```

#### `/tdd-workflow` 详解

**操作步骤:**
1. 编写用户故事 (`As a [role]...`)
2. 编写测试用例 (RED 阶段 - 测试失败)
3. 编写最小实现 (GREEN 阶段 - 测试通过)
4. 重构代码 (IMPROVE 阶段)
5. 验证 80%+ 覆盖率

**适用场景:**
- 新功能开发
- Bug 修复
- 重构代码
- 添加 API 端点

#### `/graphify` 详解

**核心功能:**
- 将代码/文档/图片转换为知识图谱
- 社区检测发现隐藏关联
- 生成交互式 HTML 和 JSON

**使用方式:**
```
/graphify                              # 分析当前目录
/graphify <path>                       # 分析指定路径
/graphify <path> --mode deep            # 深度提取
/graphify <path> --update              # 增量更新
/graphify query "<question>"            # 查询图谱
/graphify path "A" "B"                 # 查找 A 到 B 的路径
/graphify explain "概念名"              # 解释某个概念
```

**输出:**
- `graph.html` - 交互式图谱
- `GRAPH_REPORT.md` - 分析报告
- `graph.json` - 原始数据

## Hooks（钩子）

Hooks 是在特定事件发生时自动执行的操作。

### 配置位置

`~/.Codex/settings.json`

### Hook 类型

| 类型 | 触发时机 | 用途 |
|------|----------|------|
| `PreToolUse` | 工具执行前 | 验证、参数修改 |
| `PostToolUse` | 工具执行后 | 自动格式化、检查 |
| `Stop` | 会话结束时 | 最终验证 |

### 示例配置

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "command": "pnpm prettier --write \"$FILE_PATH\"",
        "description": "自动格式化代码"
      }
    ],
    "PreToolUse": [
      {
        "matcher": "Write",
        "command": "node -e \"...检查文件大小...\"",
        "description": "阻止超大文件写入"
      }
    ]
  }
}
```

## 使用技巧

### 1. 选择正确的工具

```
简单任务 → 直接使用 slash command
复杂任务 → 使用 planner 规划后执行
并行任务 → 同时启动多个 agent
```

### 2. 任务流程

```
研究 → 规划 (planner) → TDD 开发 → 代码审查 → 提交
```

### 3. 强制审查触发

以下情况必须进行代码审查:
- 编写或修改代码后
- 提交到共享分支前
- 涉及安全敏感代码
- 涉及架构变更

### 4. 安全第一

涉及以下内容时，强制使用 `security-reviewer`:
- 认证/授权
- 用户输入
- 数据库操作
- 支付/金融
- 加密操作

### 5. 性能考虑

```
上下文 > 80% → 避免大型重构
         → 避免多文件功能实现
         → 避免复杂调试
```
