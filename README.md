# Agent Skills

A personal collection of reusable agent skills, organized as one folder per skill.

Each skill directory typically contains a `SKILL.md` with usage instructions plus any supporting scripts, references, and assets.

## Structure

- One top-level directory per skill (e.g. `archify/`, `docx/`, `skill-creator/`).
- Some skills include plugin manifests (`.claude-plugin/`, `.cursor-plugin/`) and GitHub workflow configs.

See each skill's `SKILL.md` for details.
